# Actos administrativos

Esta carpeta está destinada a los PDF de acuerdos, resoluciones, decretos, leyes, actas u otros actos que sustenten las efemérides.

Convención recomendada de nombre:

`AAAA_tipo_numero_entidad.pdf`

Ejemplo:

`1989_acuerdo_125_maestria_ciencias_biologia.pdf`

Cuando exista más de un acto para la misma entidad, se conservan todos. El JSON permite asociar varios documentos a un mismo hito.
